# 🏨 SmartHotel - User Training Guide

## 👥 **For Hotel Staff**

---

## 📊 **Admin Dashboard Overview**

### **Accessing the Admin Panel**
1. Go to your hotel website
2. Click "Admin Login" or navigate to `/admin`
3. Enter your credentials:
   - **Super Admin:** Full access to all features
   - **Manager:** Access to most features
   - **Receptionist:** Limited access to bookings and rooms

---

## 🏠 **Room Management**

### **Managing Rooms**
**Location:** Admin → Rooms

#### **Adding a New Room:**
1. Click "Add Room" button
2. Fill in room details:
   - Room Number (e.g., 101, 102)
   - Room Type (Standard, Deluxe, Suite, Presidential)
   - Price per night
   - Capacity (number of guests)
   - Floor number
   - Size in square meters
   - Amenities (WiFi, TV, Mini Bar, etc.)
3. Set room status (Available, Occupied, Maintenance, Reserved)
4. Click "Create Room"

#### **Editing Room Information:**
1. Find the room in the list
2. Click "Edit" button
3. Update any information
4. Click "Update Room"

#### **Managing Room Status:**
- **Available:** Room is ready for booking
- **Occupied:** Guest is currently staying
- **Maintenance:** Room needs repairs/cleaning
- **Reserved:** Room is booked but guest hasn't arrived

---

## 📅 **Booking Management**

### **Managing Reservations**
**Location:** Admin → Bookings

#### **Viewing Bookings:**
- See all reservations with guest details
- Filter by status (Pending, Confirmed, Checked-in, Checked-out)
- Search by guest name, room number, or confirmation code

#### **Confirming Bookings:**
1. Find pending booking
2. Click "Update Status"
3. Change status to "Confirmed"
4. Guest will receive confirmation email

#### **Check-In Process:**
1. Find guest's booking
2. Click "Update Status"
3. Change status to "Checked-in"
4. Update room status to "Occupied"

#### **Check-Out Process:**
1. Find guest's booking
2. Click "Update Status"
3. Change status to "Checked-out"
4. Update room status to "Available"

## 📋 **Task Management**

### **Assigning Tasks**
**Location:** Admin → Tasks

#### **Creating Tasks:**
1. Click "Create Task"
2. Fill in task details:
   - Task title and description
   - Priority level (Urgent, High, Medium, Low)

3. Click "Create Task"

#### **Managing Tasks:**
- Track task status (Pending, In Progress, Completed)
- Filter by priority or type
- Update task progress
- Mark tasks as completed

## 📱 **QR Code System**

### **Room Service Ordering**
**Location:** Admin → QR Codes

#### **Generating QR Codes:**
1. Select room number
2. Enter guest ID
3. Generate QR code
4. Print and place in room

#### **How It Works:**
- Guests scan QR code with phone
- Direct access to room service menu
- Orders automatically linked to room
- Kitchen receives order notifications

## 🆘 **Troubleshooting**

### **Common Issues:**

#### **Booking Problems:**
- **Issue:** Guest can't find booking
- **Solution:** Search by confirmation code or guest name
- **Prevention:** Always provide confirmation number

#### **Room Status Issues:**
- **Issue:** Room shows as occupied but is empty
- **Solution:** Update room status manually
- **Prevention:** Regular status updates during check-out

#### **Payment Problems:**
- **Issue:** Payment not processing
- **Solution:** Check Stripe configuration
- **Alternative:** Process payment manually

#### **Email Notifications:**
- **Issue:** Guests not receiving emails
- **Solution:** Check email configuration
- **Alternative:** Send manual confirmation
