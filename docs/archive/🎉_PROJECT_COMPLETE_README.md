## 🚀 GO LIVE IN 90 MINUTES

### **Step 1: Add Environment Variables** (30 min)

Create `.env.local` file:

```bash
# Database (✅ already configured)
DATABASE_URL="your-mongodb-url"

# Auth (✅ already configured)
NEXTAUTH_SECRET="your-secret"
NEXTAUTH_URL="https://your-domain.com"

# Email (📧 see EMAIL_CONFIGURATION_GUIDE.md)
SMTP_HOST="smtp.gmail.com"
SMTP_USER="your-email@gmail.com"
SMTP_PASS="your-app-password"

# Stripe (💳 see STRIPE_CONFIGURATION_GUIDE.md)
STRIPE_SECRET_KEY="sk_live_..."
STRIPE_PUBLISHABLE_KEY="pk_live_..."

# Google (📍 see GOOGLE_SERVICES_SETUP.md)
NEXT_PUBLIC_GA_ID="G-XXXXXXXXXX"
```

### **Step 2: Test Locally** (30 min)

```bash
npm run dev

# Test these:
- Admin login (admin@smarthotel.com / admin123)
- Create a test booking
- Manage rooms
- Process an order
- Check all admin pages
```

### **Step 3: Deploy** (30 min)

```bash
# Option 1: Vercel (Recommended)
vercel --prod

# Option 2: Already deployed?
# Just add environment variables in Vercel dashboard
```

**That's it! You're live!** 🎉
