# API-007 - Inconsistent Zod Error Formatting

## Severity

P3 - Low

---

## Category

API

---

## Description

Validation failures return raw arrays (`error.errors`) in some routes and formatted objects (`error.format()`) in others.

---

## Affected Files

- app/api/rooms/[id]/route.ts
app/api/admin/housekeeping/rooms/route.ts

---

## Root Cause

Lack of global error handling middleware.

---

## Production Impact

- Frontend requires multiple error parsing logic trees.

---

## How to Reproduce

Trigger validation errors on both endpoints.

---

## Fix Guide

Step 1: Create a unified error response utility function.

---

## Acceptance Criteria

- Consistent error shapes across API.

---

## Regression Tests

- API error response tests.
