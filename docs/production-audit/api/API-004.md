# API-004 - Bookings Payload Disconnect (Zod Strip)

## Severity

P1 - High

---

## Category

API

---

## Description

Frontend sends nested `guestInfo`, but backend Zod expects flat keys (`guestName`). Zod silently strips the nested payload, creating bookings without guest details.

---

## Affected Files

- app/api/bookings/route.ts
app/booking/page.tsx

---

## Root Cause

Mismatched schema contracts between client and server.

---

## Production Impact

- Anonymous bookings created in the system without contact info.

---

## How to Reproduce

Submit booking from UI. Check DB to see guestName is null.

---

## Fix Guide

Step 1: Align frontend payload structure with backend Zod schema.

---

## Acceptance Criteria

- Bookings are created with accurate guest details.

---

## Regression Tests

- Checkout flow E2E tests.

---

## Priority

Sprint 1

---

## Resolution

- **Action Taken**: Modified `lib/booking-api.ts`'s `createBooking` function to correctly map `guestInfo` to `guestName`, `guestEmail`, and `guestPhone` before sending the POST request to the backend.
- **Verification**: Checked payload serialization. Types correctly align between UI form and backend Zod schema.
