# API-010 - Cross-Property Housekeeping IDOR

## Severity

P0 - Critical

---

## Category

API

---

## Description

Managers can update room statuses at properties they do not manage.

---

## Affected Files

- app/api/admin/housekeeping/rooms/route.ts

---

## Root Cause

Route verifies role but not property scope.

---

## Production Impact

- Sabotage or accidental modification of other tenants' data.

---

## How to Reproduce

Manager of Property A sends PUT request for Room ID of Property B.

---

## Fix Guide

Step 1: Validate that `room.propertyId === session.user.propertyId` before updating.

---

## Acceptance Criteria

- Returns 403 if modifying cross-property.

---

## Regression Tests

- Multi-tenant security tests.

---

## Priority

Sprint 1

---

## Resolution

- **Action Taken**: Used `getEffectivePropertyId(req)` to retrieve the active scoped property for the admin. Validated that `oldRoom.propertyId === propertyId` before allowing status updates via `PUT /api/admin/housekeeping/rooms`.
- **Verification**: Managers can no longer modify the status of rooms belonging to properties outside their permitted scope, receiving a 403 Forbidden.
