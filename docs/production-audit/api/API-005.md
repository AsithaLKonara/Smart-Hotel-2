# API-005 - Schema Relation Crash (DELETE room)

## Severity

P2 - Medium

---

## Category

API

---

## Description

`DELETE /api/rooms/[id]` checks for `roomId` on `Booking`, which doesn't exist (uses `roomAssignments`). Throws Prisma panic 500 instead of 400.

---

## Affected Files

- app/api/rooms/[id]/route.ts

---

## Root Cause

Outdated Prisma query in the delete handler after schema evolution.

---

## Production Impact

- Unhandled 500 errors on admin delete operations.

---

## How to Reproduce

Attempt to delete a room that has active assignments.

---

## Fix Guide

Step 1: Update Prisma query to check `roomAssignments: { some: { roomId: id } }`.

---

## Acceptance Criteria

- Returns correct 400 error message if room is in use.

---

## Regression Tests

- Admin room management tests.

---

Sprint 2
