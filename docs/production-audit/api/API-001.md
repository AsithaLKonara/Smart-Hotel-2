# API-001 - Bookings Array Response Mismatch

## Severity

P1 - High

---

## Category

API

---

## Description

Frontend expects `Booking[]` but API returns `{ bookings: Booking[] }`. Frontend crashes calling array methods on the object.

---

## Affected Files

- lib/booking-api.ts
app/api/bookings/route.ts

---

## Root Cause

API refactored to wrap responses without updating frontend clients.

---

## Production Impact

- Complete failure to load user bookings page.

---

## How to Reproduce

Navigate to user bookings dashboard.

---

## Fix Guide

Step 1: Update `lib/booking-api.ts` to extract `.bookings` from the response JSON.

---

## Acceptance Criteria

- User dashboard renders successfully.

---

## Regression Tests

- Frontend E2E tests for booking dashboard.

---

## Priority

Sprint 1

---

## Status

Resolved

---

## Assigned To

Antigravity

---

## Remediation Notes

- Updated `lib/booking-api.ts` to extract `.bookings` from the returned JSON payload.
- Fixed a bug in `components/ui/search-bar.tsx` which was incorrectly trying to parse `bookingsData.items` instead of `bookingsData.bookings`, ensuring that global search properly discovers bookings.
- The `app/api/bookings/route.ts` API envelope structure remained unmodified to avoid breaking downstream integration flows.
