# PAY-001 - Hard Crash on Refund Webhooks (Missing roomId)

## Severity

P0 - Critical

---

## Category

PAYMENTS

---

## Description

Webhook attempts to free room via `payment.booking.roomId`, which doesn't exist. Causes 500 panic.

---

## Affected Files

- app/api/webhooks/stripe/route.ts

---

## Root Cause

Outdated schema reference in Stripe webhook handler.

---

## Production Impact

- Refunds fail to update DB. Stripe retries endlessly.

---

## How to Reproduce

Trigger a refund webhook via Stripe CLI.

---

## Fix Guide

Step 1: Update Prisma query to traverse `roomAssignments`.

---

## Acceptance Criteria

- Webhook returns 200 and frees room.

---

## Regression Tests

- Stripe webhook integration tests.

---

Sprint 1
