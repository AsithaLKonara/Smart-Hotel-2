# PAY-003 - Out-of-Order Webhook Overwrites

## Severity

P1 - High

---

## Category

PAYMENTS

---

## Description

Stripe webhooks are processed without checking current DB state. A `payment_failed` arriving after `succeeded` will erroneously fail the booking.

---

## Affected Files

- app/api/webhooks/stripe/route.ts

---

## Root Cause

Lack of state machine constraints on webhook updates.

---

## Production Impact

- Successful bookings marked as failed.

---

## How to Reproduce

Send `payment_failed` event after `succeeded` event.

---

## Fix Guide

Step 1: Ensure state transitions are strictly directional (e.g., cannot transition from `completed` to `failed`).

---

## Acceptance Criteria

- Late `payment_failed` is ignored if status is already `completed`.

---

## Regression Tests

- Webhook ordering tests.

---

## Priority

Sprint 1
