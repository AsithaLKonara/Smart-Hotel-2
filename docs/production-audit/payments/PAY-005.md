# PAY-005 - Webhook Deduplication Bypass (Redis Fail-Open)

## Severity

P1 - High

---

## Category

PAYMENTS

---

## Description

If Redis is down, Stripe webhook intentionally bypasses deduplication, allowing duplicate event processing.

---

## Affected Files

- app/api/webhooks/stripe/route.ts

---

## Root Cause

Misguided "fail open" logic for distributed locking.

---

## Production Impact

- Transaction deadlocks or duplicate refund processing.

---

## How to Reproduce

Disable Redis, fire duplicate webhooks.

---

## Fix Guide

Step 1: Fail closed (503) if deduplication engine is unavailable, forcing Stripe to retry later.

---

## Acceptance Criteria

- Returns 503 if Redis is unreachable.

---

## Regression Tests

- Webhook resilience tests.

---

## Priority

Sprint 2
