# CFG-003 - Optional Variables Incorrectly Required

## Severity

P2 - Medium

---

## Category

CONFIGURATION

---

## Description

Pusher keys are marked optional but code requires them for stability (INT-005).

---

## Affected Files

- env.example
lib/realtime.ts

---

## Root Cause

Mismatch between feature flags and module initialization.

---

## Production Impact

- Startup failures.

---

## How to Reproduce

Run without Pusher keys.

---

## Fix Guide

Step 1: Implement feature toggles for Pusher.

---

## Acceptance Criteria

- System boots gracefully without keys.

---

## Regression Tests

- Boot sequence tests.

---

## Priority

Sprint 3
