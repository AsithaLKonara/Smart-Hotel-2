# DB-009 - Nullable Multi-Tenant Fields (propertyId)

## Severity

P0 - Critical

---

## Category

DATABASE

---

## Description

`propertyId` is optional on critical models. Missing `propertyId` causes tenant data bleed.

---

## Affected Files

- prisma/schema.prisma

---

## Root Cause

Schema evolved to support multi-tenancy without enforcing it retroactively.

---

## Production Impact

- Guests at Hotel A seeing bookings for Hotel B.

---

## How to Reproduce

Create a room without a propertyId. Query rooms by propertyId.

---

## Fix Guide

Step 1: Backfill missing `propertyId` values.
Step 2: Make `propertyId` required in schema.

---

## Acceptance Criteria

- Prisma schema validation passes with required field.

---

## Regression Tests

- Multi-tenant data isolation tests.

---

## Priority

Sprint 1
