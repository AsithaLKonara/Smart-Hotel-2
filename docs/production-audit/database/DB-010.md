# DB-010 - Floating Point Currency Precision Loss

## Severity

P1 - High

---

## Category

DATABASE

---

## Description

Currency values are stored as `Float`, leading to IEEE 754 precision rounding errors (e.g., 0.1 + 0.2 = 0.30000000000000004).

---

## Affected Files

- prisma/schema.prisma (FolioLineItem, Payment, Booking)

---

## Root Cause

Prisma schema uses `Float` instead of `Decimal` or `Int` (cents).

---

## Production Impact

- Financial reconciliation failures during Night Audits.

---

## How to Reproduce

Post charges that result in floating point errors and check folio totals.

---

## Fix Guide

Step 1: Migrate currency fields to `Decimal` in Prisma schema.
Step 2: Update frontend to handle Decimal string conversions.

---

## Acceptance Criteria

- Verify exact arithmetic on folio totals.

---

## Regression Tests

- Night Audit calculations.
