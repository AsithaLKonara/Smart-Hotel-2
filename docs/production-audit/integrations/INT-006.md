# INT-006 - SMTP Silent Dropping of Critical Notifications

## Severity

P2 - Medium

---

## Category

INTEGRATIONS

---

## Description

Nodemailer errors are swallowed. No outbox pattern means emails are lost permanently if SMTP is down.

---

## Affected Files

- lib/email.ts

---

## Root Cause

Synchronous email sending designed to not block API responses.

---

## Production Impact

- Guests do not receive confirmations.

---

## How to Reproduce

Block outbound port 587, create booking.

---

## Fix Guide

Step 1: Implement queue (BullMQ/Outbox).

---

## Acceptance Criteria

- Failed emails remain in queue.

---

## Regression Tests

- Email delivery system tests.

---

## Priority

Sprint 3
