# INT-003 - Booking.com Missing Lifecycle Orchestration

## Severity

P1 - High

---

## Category

INTEGRATIONS

---

## Description

OTA booking creates a reservation but fails to create `Folio` or `RoomAssignment`. Guests cannot be checked out or billed.

---

## Affected Files

- lib/ota/webhook-handler.ts

---

## Root Cause

Incomplete implementation of the reservation pipeline in the OTA handler.

---

## Production Impact

- Broken PMS lifecycle for OTA guests.

---

## How to Reproduce

Ingest OTA booking. Observe missing Folio in DB.

---

## Fix Guide

Step 1: Ensure OTA handler calls core Booking creation services that establish Folios/Assignments.

---

## Acceptance Criteria

- OTA bookings have Folios and RoomAssignments.

---

## Regression Tests

- Database integrity audit script.

---

## Priority

Sprint 2
