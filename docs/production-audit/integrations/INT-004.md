# INT-004 - Pusher Synchronous Crashing in Webhooks

## Severity

P1 - High

---

## Category

INTEGRATIONS

---

## Description

Pusher events emitted synchronously after DB transactions without try/catch. Pusher failure crashes Stripe webhook.

---

## Affected Files

- app/api/webhooks/stripe/route.ts

---

## Root Cause

Missing error boundaries on non-critical side effects.

---

## Production Impact

- Infinite Stripe retries and repeated DB transactions.

---

## How to Reproduce

Disconnect Pusher credentials, fire Stripe webhook.

---

## Fix Guide

Step 1: Wrap `RealtimeEvents.emitBookingUpdated` in try/catch.

---

## Acceptance Criteria

- Webhook returns 200 even if Pusher fails.

---

## Regression Tests

- Webhook resilience tests.

---

## Priority

Sprint 2
