# INT-001 - Booking.com Unauthenticated Webhooks

## Severity

P0 - Critical

---

## Category

INTEGRATIONS

---

## Description

OTA Webhook accepts XML payloads with no authentication, signature verification, or IP allowlisting.

---

## Affected Files

- app/api/integrations/booking-com/webhook/route.ts

---

## Root Cause

Endpoint deployed without security middleware.

---

## Production Impact

- Anyone can modify, create, or cancel guest reservations.

---

## How to Reproduce

Run `api-contract-check.ts`.

---

## Fix Guide

Step 1: Implement IP allowlisting (Booking.com subnets) and/or API Key validation.

---

## Acceptance Criteria

- Reject unauthenticated requests with 401/403.

---

## Regression Tests

- API Contract audit script.

---

## Priority

Sprint 1
