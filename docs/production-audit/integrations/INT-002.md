# INT-002 - Booking.com Concurrency Overbooking

## Severity

P0 - Critical

---

## Category

INTEGRATIONS

---

## Description

OTA handler bypasses `InventoryLockEngine` entirely, allowing concurrent webhooks to double-book rooms.

---

## Affected Files

- lib/ota/webhook-handler.ts

---

## Root Cause

Missing integration between webhook handler and core inventory engine.

---

## Production Impact

- Overbooked hotel.

---

## How to Reproduce

Run `booking-concurrency-test.ts`.

---

## Fix Guide

Step 1: Integrate `InventoryLockEngine` into `processOtaReservation`.

---

## Acceptance Criteria

- Concurrency test blocks duplicate reservations.

---

## Regression Tests

- `booking-concurrency-test.ts`
