# INT-007 - Groq API Key Fallback Vulnerability

## Severity

P1 - High

---

## Category

INTEGRATIONS

---

## Description

Groq SDK initializes with "BUILD_PLACEHOLDER" if key is missing, causing 401s at runtime instead of failing at boot.

---

## Affected Files

- lib/chatbot/groq.ts

---

## Root Cause

Developer hack to pass CI build without secrets.

---

## Production Impact

- Broken chatbot in production.

---

## How to Reproduce

Remove GROQ_API_KEY, use chatbot.

---

## Fix Guide

Step 1: Throw error at runtime if key is "BUILD_PLACEHOLDER".

---

## Acceptance Criteria

- Chatbot gracefully returns disabled message if unconfigured.

---

## Regression Tests

- Integration health check script.

---

## Priority

Sprint 2
