# INT-009 - Cloudinary Ghost Integration

## Severity

P3 - Low

---

## Category

INTEGRATIONS

---

## Description

Cloudinary documented but not present in `next.config.js` or CSP. Loading images will cause severe CSP violations.

---

## Affected Files

- next.config.js
docs/archive/ALL_REQUIRED_ENV_VARIABLES.md

---

## Root Cause

Incomplete integration deployment.

---

## Production Impact

- Broken images on frontend.

---

## How to Reproduce

Render Cloudinary image on UI.

---

## Fix Guide

Step 1: Add Cloudinary to CSP and `remotePatterns` in next.config.js.

---

## Acceptance Criteria

- Images load without console errors.

---

## Regression Tests

- UI asset tests.
