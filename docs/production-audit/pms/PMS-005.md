# PMS-005 - Audit Log Attribution Forgery

## Severity

P1 - High

---

## Category

PMS

---

## Description

Night Audit selects a random checked-in guest to attribute the financial close action (`runByUserId`), destroying chain of custody.

---

## Affected Files

- app/api/cron/night-audit/roll-forward/route.ts

---

## Root Cause

Hacky implementation to bypass required non-null constraints on log tables.

---

## Production Impact

- Compliance failure. Financial logs attributed to guests.

---

## How to Reproduce

Run night audit. Check `NightAuditLog` table.

---

## Fix Guide

Step 1: Create a dedicated `SYSTEM` user ID and use it for all cron executions.

---

## Acceptance Criteria

- Audit logs correctly attribute `SYSTEM`.

---

## Regression Tests

- Audit log integrity tests.

---

## Priority

Sprint 2
