# PMS-004 - Broken No-Show Processing

## Severity

P2 - Medium

---

## Category

PMS

---

## Description

Night audit attempts to find `EXPECTED` Stays, but Stays are only created at Check-in (`CHECKED_IN`). Query always returns 0.

---

## Affected Files

- app/api/cron/night-audit/roll-forward/route.ts

---

## Root Cause

Misunderstanding of the `Stay` model lifecycle.

---

## Production Impact

- No-shows are never processed, tying up room inventory.

---

## How to Reproduce

Run night audit with a booking that should be a no-show.

---

## Fix Guide

Step 1: Query `Booking` model for `status === "CONFIRMED"` and `checkIn < NOW()`.

---

## Acceptance Criteria

- No-show bookings are correctly cancelled.

---

## Regression Tests

- Night audit no-show tests.

---

## Priority

Sprint 2
