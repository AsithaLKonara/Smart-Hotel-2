# PMS-003 - Financial Engine In-Memory State Loss

## Severity

P0 - Critical

---

## Category

PMS

---

## Description

`FinancialEngine` stores active folios in an in-memory Map. Restarts wipe the Map, causing subsequent charge postings to crash.

---

## Affected Files

- lib/financial-engine.ts

---

## Root Cause

Stateful architecture in a stateless (serverless) deployment model.

---

## Production Impact

- Inability to post POS charges or checkout guests after process restart.

---

## How to Reproduce

Check in guest. Restart Node server. Attempt to post charge.

---

## Fix Guide

Step 1: Remove in-memory Map. Lazy-load `Folio` state from PostgreSQL via Prisma when posting charges.

---

## Acceptance Criteria

- Charges succeed even after server restarts.

---

## Regression Tests

- Financial engine state recovery tests.

---
